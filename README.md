# LYNKO

Book with LYNKO — a smart appointment-scheduling dashboard for small and
medium businesses. Hebrew, RTL.

## Stack

Next.js 16 (App Router), TypeScript, Tailwind CSS v4, Framer Motion.

## Getting Started

```bash
npm install
npm run dev
```

Open [http://localhost:3000](http://localhost:3000) to see it running.
